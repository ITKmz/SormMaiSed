# SormMaiSed

SormMaiSed is a Laravel project created for a Database subject. It is a system designed for maintenance and servicing of IT equipment, with the ability to track results.

## How to Run

1. Install dependencies using Composer and npm:
   ```bash
   composer install
   npm install
   ```

2. Run the development server:
   ```bash
   php artisan serve
   ```

3. Compile assets:
   ```bash
   npm run dev
   ```

Now you can access the system in your browser.
